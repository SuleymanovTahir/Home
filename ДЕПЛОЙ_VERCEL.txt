══════════════════════════════════════════════════
  1. ПЕРВЫЙ ЗАПУСК CLI
══════════════════════════════════════════════════

Если Vercel CLI ещё не авторизован на этом компьютере:

  npx vercel login

Затем свяжите папку именно с проектом home:

  cd "/Users/tahir/Desktop/дом"
  npm install
  npx vercel link --yes --project home --scope wow-0a3d

При запросе войдите в аккаунт Vercel и убедитесь, что выбран проект
wow-0a3d / home. Связь сохраняется в локальной папке .vercel/ и не
нуждается в повторной настройке при следующих запусках.

══════════════════════════════════════════════════
  2. ПОВТОРНЫЙ PROD-ДЕПЛОЙ
══════════════════════════════════════════════════

После изменения кода запускайте команды из корня этого проекта:

  cd "/Users/tahir/Desktop/дом"
  npm run build:upload-client
  npx vercel project inspect --non-interactive
  npx vercel deploy --prod --yes

Или одной строкой из любой папки:

  cd "/Users/tahir/Desktop/дом" && npm run build:upload-client && npx vercel project inspect --non-interactive && npx vercel deploy --prod --yes

Перед деплоем команда inspect должна показать проект home в области
wow-0a3d. Если CLI сообщает, что папка связана с другим проектом,
остановитесь и повторите шаг 1 с правильной папкой.

Изменения каталога (загрузка, переименование, скрытие, порядок и удаление)
сохраняются сразу в Blob и не требуют деплоя. Эти команды нужны, когда
меняется код сайта или панели.

══════════════════════════════════════════════════
  3. ПРОВЕРКА ПОСЛЕ ДЕПЛОЯ
══════════════════════════════════════════════════

Откройте:

  https://home-two-tau-26.vercel.app/
  https://home-two-tau-26.vercel.app/admin.html

На главной должны быть ссылки на модели и кнопка управления. В панели
войдите с паролем ADMIN_PASSWORD, загрузите HTML-модель, переименуйте её
значком ручки и проверьте каталог.

Настройки и пароли остаются в Vercel Environment Variables. Не добавляйте
секреты, токены или файлы .env в команды, репозиторий или этот документ.

══════════════════════════════════════════════════
  4. ДЕПЛОЙ ЧЕРЕЗ GIT
══════════════════════════════════════════════════

Vercel также автоматически публикует новые изменения после push ветки
main. Для этого проекта ручной CLI-деплой выше использует текущую локальную
папку и не требует повторной авторизации Vercel MCP-коннектора.
