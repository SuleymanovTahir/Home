# Каталог 3D-моделей дома

Главная страница показывает опубликованные модели. Владелец сайта управляет ими на `/admin.html`: можно загружать отдельные HTML-модели, скрывать и показывать их, менять порядок и удалять. Новые модели и изменения каталога сохраняются в Vercel Blob и становятся видны сразу, без нового Git-коммита или деплоя сайта.

Исходные HTML-файлы моделей не меняются. Их неизменённые копии в `model-sources/` нужны только для универсального просмотрщика. Каталог хранит название, описание, порядок и видимость; новые HTML загружаются как есть в закрытое хранилище. Старые ссылки проходят через просмотрщик и учитывают состояние модели в каталоге.

## Однократная настройка Vercel

1. В проекте `home-two-tau-26` откройте **Storage** и создайте подключённый к проекту **Vercel Blob** store с режимом доступа **Private**. Vercel подключит Blob credentials к проекту.
2. В **Settings → Environment Variables** добавьте `ADMIN_PASSWORD` (случайный пароль длиной от 16 символов) и `SESSION_SECRET` (случайное значение длиной не менее 32 символов; сгенерируйте через `openssl rand -hex 32`). Добавьте их для Production.
3. После сохранения переменных создайте новый Production deployment.
4. Откройте `/admin.html`, войдите с `ADMIN_PASSWORD` и загружайте `.html`-модели размером до 3 МБ.

Файлы из Blob остаются закрытыми. Публичный просмотр проходит через серверную функцию с sandbox-политикой, а изменения каталога доступны только после входа владельца.
