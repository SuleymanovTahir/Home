# Каталог 3D-моделей дома

Главная страница показывает опубликованные модели. Владелец сайта управляет ими напрямую на `/admin.html`: можно загружать отдельные HTML-модели, переименовывать, скрывать и показывать их, менять порядок и удалять. Новые HTML-файлы отправляются напрямую в приватный Vercel Blob, а каталог обновляется сразу, без нового Git-коммита или деплоя сайта. У приложения нет собственного лимита размера; предел платформы Vercel Blob — 5 ТБ на файл.

Исходные HTML-файлы моделей не меняются. Их неизменённые копии в `model-sources/` нужны только для универсального просмотрщика. Каталог хранит название, описание, порядок и видимость; новые HTML загружаются как есть в закрытое хранилище. Старые ссылки проходят через просмотрщик и учитывают состояние модели в каталоге.

## Однократная настройка Vercel

1. В проекте `home-two-tau-26` откройте **Storage** и создайте подключённый к проекту **Vercel Blob** store с режимом доступа **Private**. Vercel подключит Blob credentials к проекту.
2. В **Settings → Environment Variables** добавьте `ADMIN_PASSWORD` (сгенерируйте случайное значение командой `openssl rand -hex 32`). Добавьте его для Production и храните в менеджере паролей.
3. После сохранения переменных создайте новый Production deployment.
4. Откройте `/admin.html`, войдите с `ADMIN_PASSWORD` и загружайте `.html`-модели.

Файлы из Blob остаются закрытыми. Большие файлы загружаются напрямую через подписанный временный URL; Vercel Blob использует multipart-загрузку для больших файлов. Публичный просмотр проходит через серверную функцию с sandbox-политикой, а изменения каталога доступны только после входа владельца.

## Деплой из терминала

Пошаговая инструкция для CLI находится в [`ДЕПЛОЙ_VERCEL.txt`](./ДЕПЛОЙ_VERCEL.txt). В первый раз выполните вход и свяжите папку с проектом `wow-0a3d/home`; затем каждый production-деплой запускается из корня этого проекта.

Если менялся код загрузчика, перед деплоем пересоберите браузерный модуль командой `npm run build:upload-client`.
